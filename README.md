# NestJS Tam Rehber

Bu dokümantasyon, NestJS framework'ünü **temel seviyeden uzman seviyeye kadar** öğrenmek isteyen geliştiriciler için hazırlanmış kapsamlı bir rehberdir. Modern backend geliştirme süreçlerinde ihtiyaç duyulan temel kavramları, mimari yaklaşımları ve production ortamlarında kullanılan ileri düzey özellikleri kapsamaktadır.

##  Amaç

NestJS kullanarak ölçeklenebilir, sürdürülebilir ve kurumsal seviyede backend uygulamaları geliştirmek için gereken bilgi ve pratikleri tek bir kaynak altında sunmak.

---

## 📚 İçerik

### Temel Seviye

* NestJS'e Giriş
* Kurulum ve Proje Yapısı
* Controller Yapısı
* Service Katmanı
* Dependency Injection (DI)
* Module Sistemi

### Orta Seviye

* DTO (Data Transfer Object)
* Validation ve Pipes
* TypeORM Entegrasyonu
* Veritabanı İşlemleri
* Authentication ve JWT
* Config & Environment Yönetimi

### İleri Seviye

* Guards ve Yetkilendirme
* Middleware Kullanımı
* Interceptors
* Exception Filters
* Request & Response Yönetimi

### Uzman Seviye

* WebSocket Mimarisi
* Microservices
* CQRS Pattern
* Unit & E2E Testing
* Deployment ve Production Best Practices

---

## 👨‍💻 Kimler İçin?

Bu rehber aşağıdaki geliştiriciler için uygundur:

* NestJS öğrenmek isteyenler
* Express.js'den NestJS'e geçiş yapanlar
* Backend geliştirme kariyerine başlayanlar
* Kurumsal uygulamalar geliştiren ekipler
* Microservice mimarileri ile çalışan yazılım mühendisleri

---

##  Kazanımlar

Bu rehberi tamamladıktan sonra:

* NestJS mimarisini anlayabilir,
* REST API geliştirebilir,
* Veritabanı entegrasyonları kurabilir,
* JWT tabanlı kimlik doğrulama sistemleri geliştirebilir,
* Yetkilendirme ve güvenlik katmanları oluşturabilir,
* WebSocket ve Microservice mimarileri geliştirebilir,
* Production ortamına uygun uygulamalar hazırlayabilirsiniz.
